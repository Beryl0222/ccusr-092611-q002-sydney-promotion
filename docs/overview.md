# 悉尼文旅推介协作库说明

悉尼文旅推介协作库需要在多方参与、资料不同语言版本先后到达、事件顺序不
稳定和服务重启的情况下保持记录一致。

- 每条展项记录有所属机构、城市、状态和递增版本，全部历史版本以快照保存，
  并行编辑以调用方读过的版本为基准做字段级三方合并：改动键不重叠则自动
  合并，重叠且取值不同则拒绝；所有状态变化写入事件表。
- 翻译稿按（展项, 语言）维护独立版本与确认状态，机构不能确认自己的稿件，
  重新提交必须通过版本校验。
- 授权带生效窗口与使用范围：过期状态随时间推进独立结算提交，撤回立即
  生效；生成发布包时展项必须已定稿、翻译稿已确认、授权在发布时刻有效且
  覆盖发布渠道。
- 发布请求以 request_key 幂等：重新提交同一批请求返回同一发布包，配额
  只扣一次；任何校验失败整批回滚，不产生半包或脏扣减。
- 每个机构有交接 outbox 和确认游标，交接状态与游标落库；合作方离线或
  服务重启后，从最后确认的位置继续拉取即可恢复未完成的交接。
- 最终清单按城市、语言汇总展项版本、翻译版本、有效授权机构和内容哈希，
  整份清单再给 manifest_hash，供双方离线独立复算、逐条核验。
